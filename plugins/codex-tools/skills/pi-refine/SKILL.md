# Pi Refinement

Mode: **authorized document refinement**. Load the [shared procedure](../../references/review-and-refinement.md) and [Pi transport](../../references/pi-transport.md) before proceeding.

The parent chooses useful review perspectives and owns disposition/integration. No fixed model roster, alternating reviewer sequence, mandatory delegated writer, or persistent rotation cursor is required. Apply only accepted in-scope corrections and report unresolved decisions.
